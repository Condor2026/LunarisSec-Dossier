# Contribuciones a LunarisSec-Dossier

Gracias por tu interés en contribuir a este dossier de inteligencia de amenazas.

## 📌 Directrices generales

1. **Verificación de fuentes:** Toda la información añadida debe estar respaldada por fuentes verificables (capturas de pantalla, enlaces públicos, informes oficiales).
2. **Actualizaciones:** Si encuentras nueva información sobre LunarisSec, crea un Pull Request con la actualización.
3. **Formato:** Mantén el formato Markdown y la estructura de carpetas existente.
4. **No difundir información sensible:** Este repositorio es público, no incluyas datos personales no verificados.

## 🔍 Qué se acepta

- Nuevos IOCs (Indicadores de Compromiso)
- Actualizaciones de cronología de ataques
- Correcciones de errores en los perfiles
- Enlaces a fuentes adicionales
- Nuevos análisis tácticos

## ❌ Qué NO se acepta

- Información no verificada
- Datos personales de individuos no relacionados
- Contenido difamatorio sin pruebas
- Spam o autopromoción

## 📝 Proceso

1. Haz un fork del repositorio
2. Crea una rama con tu contribución (`feature/nueva-info`)
3. Añade tu contribución
4. Haz un Pull Request describiendo los cambios

## 📧 Contacto

Para dudas o sugerencias, abre un Issue en el repositorio.
